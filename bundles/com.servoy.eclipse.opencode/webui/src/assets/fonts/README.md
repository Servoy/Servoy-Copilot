# Bundled fonts

Latin-subset woff2 files, bundled so the UI works offline in the embedded browser.

- Inter (400, 500, 600) - Copyright 2016 The Inter Project Authors (https://github.com/rsms/inter), SIL Open Font License 1.1. See `LICENSE-Inter.txt`.
- JetBrains Mono (400, 500) - Copyright 2020 The JetBrains Mono Project Authors (https://github.com/JetBrains/JetBrainsMono), SIL Open Font License 1.1. See `LICENSE-JetBrainsMono.txt`.

Files were taken from the `@fontsource/inter` and `@fontsource/jetbrains-mono` npm packages (not project dependencies).
